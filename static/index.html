Integrasi REST API & Panduan Parameter Engine

Kirim file dokumen langsung dari backend, script automasi, atau AI Agent. Anda dapat memilih pemrosesan Local Engine (hemat Rp 0 biaya token) atau Cloud Precision (Azure Document Intelligence) via parameter engine.

⚡ Local Engine engine=local
Rp 0 Biaya Token ~1.6 Detik 100% Offline & Privat

Pilihan Default. Menggunakan pdfplumber (deteksi garis fisik sel) + PyMuPDF (decoding font langsung). Sangat akurat untuk 95% dokumen digital, tabel matriks server, KAK, dan RFP tanpa biaya API sama sekali.

☁️ Cloud Precision engine=cloud
Azure Doc Intelligence Layout Model Deep OCR

Opsi Presisi Ekstrem. Menggunakan Azure Document Intelligence (prebuilt-layout). Ideal untuk hasil scan scanner buram/miring, tulisan tangan, atau tabel dengan multi-level merged cells yang sangat rumit.

🤖 AI Vision Diagram ai_vision=true
Azure AI Vision 4.0 Arsitektur & Topologi Orthogonal (Lokal/Cloud)

Parameter Terpisah. Memotong setiap gambar arsitektur cloud / diagram topologi di dokumen, lalu meng-generate deskripsi teknis komponennya dan menginjeksinya langsung ke dalam teks Markdown. 

curl -X POST "http://localhost:8080/api/v1/extract" \
  -H "Authorization: Bearer c2t_sec_98f8a17c33d83_convert2text_token" \
  -F "file=@document.pdf" \
  -F "engine=local" \
  -F "format=markdown"

💡 Mode Local: Memproses dokumen secara instan dan 100% gratis menggunakan algoritma Python lokal tanpa konsumsi token eksternal.

📋 Tabel Referensi Parameter API
Parameter Tipe Nilai Opsi Default Keterangan Fungsi
file Binary Form PDF, DOCX, PPTX, XLSX Wajib File dokumen biner yang akan diproses dan diekstrak tabel & teksnya.
engine String Form local | cloud local local: Python parser lokal (Rp 0 cost, cepat ~1.6s).
cloud: Azure Document Intelligence Layout model (presisi tinggi untuk scan/tabel rumit).
format String Form markdown | text markdown Format hasil ekstraksi. Markdown mempertahankan struktur tabel GitHub-flavored.
ai_vision String Form true | false false Jika true, diagram arsitektur/topologi dianalisis visual menggunakan Azure AI Vision 4.0.
Authorization HTTP Header Bearer <token> - Static Barrier Token proteksi API (dikonfigurasi via API_BEARER_TOKEN di .env). Bisa juga via header X-API-Key.
