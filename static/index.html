Integrasi REST API untuk Aplikasi Anda

Kirim file binary langsung dari backend atau script automasi Anda ke REST API ini (dengan dukungan Azure AI Vision untuk OCR diagram & arsitektur solusi):

POST /api/v1/extract Respon JSON lengkap beserta metadata, statistik ekstraksi, & wawasan AI Vision 
curl -X POST "http://localhost:8080/api/v1/extract" \
  -F "file=@document.pdf" \
  -F "format=markdown" \
  -F "ai_vision=true"
POST /api/v1/extract/raw Respon langsung raw content dengan diagram OCR terinjeksi (ideal untuk Linux pipe) 
curl -X POST "http://localhost:8080/api/v1/extract/raw?ai_vision=true" \
  -F "file=@presentation.pptx" \
  -F "format=markdown" > solution.md
